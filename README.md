📌 SPAS (Standard Python ARP Spoofer) - это цветной, консольный и кроссплатформенный инструмент для ARP-спуфинга и сетевого пентестинга в локальных сетях (LAN). Программа написана на Python с использованием библиотеки Scapy и другими библиотеками для простого и комфортного использования.

<hr>
<p>💎 Возможности SPAS:</p>
<ul>
  <li>Кроссплатформенность (Работает на Windows и Linux)</li>
  <li>3 режима атаки:<ol type="1">
    <li>MITM-Spoof: Полная MITM-атака (Man In The Middle)</li>
    <li>Router-Spoof: Атака на Роутер (Перехват трафика маршрутизатора)</li>
    <li>Target-Spoof: Атака на определённую жертву (Перехват трафика жертвы)</li>
  </ol></li>
  <li>Сканирование всей сети и получение IP-MAC таблицы всех устройств</li>
  <li>Автоматизированная проверка прав администратора/root-пользователя перед запуском</li>
  <li>Автоматизированное включение/выключение IP-форвардинга</li>
  <li>Вывод баннера и таблицы доступных команд</li>
  <li>Выход из программы (командой или сочетанием клавищ Ctrl+C)</li>
</ul>
<hr>
<p>📦 Требования:</p><ul>
  <li>Права администратора/root-пользователя перед запуском</li>
  <li>Python 3.7 или выше</li>
  <li>Библиотеки: Scapy, prettytable, termcolor</li>
</ul>
<hr>
<p>⚙️ Установка:</p>
<p>Перед запуском обязательно запускайте от имени администратора или root-пользвателя. Иначе программа просто не сможет отправлять пакеты!</p>
<p>Для Windows:</p><ol>
  <li>Скачайте репозиторий</li>
  <li>Отключите антивирус WindowsDefender перед запуском SPAS или добавьте его в исключения</li>
  <li>Установите библиотеки, введя следующую команду в терминале или в командной строке: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите коммандную строку или терминал от имени администратора и запустите программу, введя команду: <code>python "Путь/к/файлу/SPAS.py"</code></li>
  <li>Готово!</li>
</ol>
<p>Для Linux:</p><ol>
  <li>Откройте терминал</li>
  <li>Введите команды:</li>
     <code>git clone https://github.com/ReDDoS-GH0ST/SPAS.git</code><br>
     <code>cd SPAS</code></li>
  <li>Установите библиотеки, введя следующую команду в терминале: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите терминал и запустите программу, введя команду: <code>sudo python "Путь/к/файлу/SPAS.py"</code></li>
  <li>Введите пароль от root-пользователя и нажмите Enter</li>
  <li>Готово!</li>
</ol>
<hr>
<p>🛠 Использование:</p>
  <p>Используйте допустимые команды:</p><ol>
    <li><code>MITM-Spoof</code> - для полного ARP-спуфинга</li>
    <li><code>Router-Spoof</code> - для ARP-спуфинга маршрутизатора</li>
    <li><code>Target-Spoof</code> - для ARP-спуфинга выбранной жертвы</li>
    <li><code>Recover</code> - для восстановления ARP-таблиц</li>
    <li><code>Wi-Fi Scan</code> - для сканирования всей сети и получения IP-MAC таблицы</li>
    <li><code>Help</code> - для получения помощи в использовании SPAS</li>
    <li><code>Clear</code> - для очищения терминала</li>
    <li><code>Banner</code> - для вывода баннера</li>
    <li><code>Quit</code> или <code>Ctrl+C</code> - для выхода из программы</li>
  </ol>
  <p>Для первых трёх команд используются IP-адреса по умолчанию (для маршрутизатора - 192.168.1.1, для жертвы - 192.168.1.100), если не вводить IP-адреса Вашего маршртизатора и/или выбранной жертвы</p>
